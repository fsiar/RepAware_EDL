# Representation as Evidence: Representation Aware Deep Evidential Regression

**WACV 2027**

**Authors:** Fatemeh Siar and Francisco C. Pereira

Technical University of Denmark (DTU)

## Overview

We propose Representation-Aware Deep Evidential Regression, a framework that incorporates latent representation support into evidential uncertainty estimation to improve reliability under distribution shift.
